# CondoVale — SVG Icon Pack

33 ícones, 4 variantes (primary, secondary, dark, white), SVG 24×24 com strokes editáveis.

Para Nuxt, copie os arquivos para `public/icons/` e use `<img src="/icons/reservations-primary.svg" alt="Reservas">`.

As cores seguem a identidade visual da referência. O símbolo de marca é uma interpretação vetorial simplificada, não uma vetorização exata do logotipo.
